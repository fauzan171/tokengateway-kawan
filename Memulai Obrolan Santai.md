### **2\. Arsitektur Integrasi: Lobe Chat \+ TokenGateway \+ Agent Engine**

Supaya **Kawanku** rasanya benar-benar mulus seperti Supernala, alur datanya di VPS kamu bisa disusun seperti ini:

> 1. **Layer 1: Front-End & Workspace (kawanku.tokengateway.ai.id)**  
   * Menggunakan **Lobe Chat (Self-Hosted Database Version)**.  
   * Kenapa harus versi *Database*? Supaya punya fitur autentikasi user (Login/Register), *history chat* tersimpan di *cloud* (bukan cuma di *browser*), dan mendukung fitur \* Knowledge Base\* (upload file).  
   * Kamu *rebrand* total: ganti logo, warna tema, dan hilangkan atribut Lobe Chat.  
> 2. **Layer 2: The Router (tokengateway.ai.id)**  
   * Semua *request* dari UI Kawanku masuk ke TokenGateway dulu.  
   * Di sini kamu memvalidasi limit kuota/token dari masing-masing user atau klien.  
> 3. **Layer 3: The Agentic Harness (Python Backend \- FastAPI \+ LangGraph)**  
   * Untuk model standar (misal user pilih gpt-4o atau deepseek-chat), TokenGateway langsung meneruskan ke *provider* asli.  
   * **Trik Supernala-nya:** Kamu buat satu atau beberapa "Model Virtual" di TokenGateway, misalnya diberi nama **kawanku-deep-research** atau **kawanku-agent-pro**.  
   * Ketika user memilih model tersebut, TokenGateway meneruskan *request*\-nya ke *service* **LangGraph / CrewAI** lokal di VPS kamu.

## **3\. Fitur Utama & Spesifikasi Fungsional (Core Features)**

### **A. Autentikasi & Manajemen Workspace (Better Auth)**

> * **Pendaftaran & Login:** Sistem login berbasis email/password atau *magic link*.  
> * **Workspace Isolation:** Setiap user otomatis memiliki *Workspace ID* unik. Riwayat chat, file hasil generate, dan kuota token terisolasi di dalam workspace masing-masing.

### **C. Workspace Computer & Background Workers (Async Jobs)**

> * **Background Processing:** Tugas berat (seperti pencarian web mendalam atau *rendering* file Excel) berjalan secara asinkron di *backend worker* agar UI tidak mengalami *timeout*.

> * **Scraper:** Menggunakan **Crawl4AI** untuk mengambil isi halaman web dan mengubahnya menjadi *Markdown* bersih sebelum dikirim ke LLM.

### **E. Instant Artifact & Document Generator**

> * **Spreadsheet Generator:** Tool backend untuk merakit file .xlsx secara instan dari struktur JSON agen (tanpa overhead eksekusi Python bebas yang berat).
