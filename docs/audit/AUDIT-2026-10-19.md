## Perintah probe AUD-01 (persis, keluaran aman)

Perintah berikut dijalankan terhadap koneksi aktif lokal. Ia hanya membaca DB; dua POST bertujuan diagnostik gateway. Variabel `key` dan isi pesan tidak dicetak.

```bash
npx tsx --env-file-if-exists=.env -e 'import {loadConfig} from "./src/lib/config/env.ts"; import {getDb,closeDb} from "./src/lib/db.ts"; import {decryptSecret,CONNECTION_API_KEY_PURPOSE} from "./src/lib/secrets/index.ts"; (async()=>{const cfg=loadConfig();const db=await getDb(cfg.databaseUrl);const g=await db.generation.findFirstOrThrow({where:{errorCode:"UPSTREAM_ERROR"},orderBy:{createdAt:"desc"}});const chat=await db.chat.findUniqueOrThrow({where:{id:g.chatId}});const u=await db.chatMessage.findUniqueOrThrow({where:{id:g.userMessageId}});const content=JSON.parse(u.contentJson).parts.filter((p:any)=>p.kind==="text").map((p:any)=>p.text).join("");const con=await db.connection.findFirstOrThrow({where:{userId:chat.userId,isActive:1}});const key=decryptSecret({envelope:con.apiKeyEncrypted,key:cfg.encryptionKey,aad:{rowId:con.id,userId:chat.userId,purpose:CONNECTION_API_KEY_PURPOSE}});for(const [label,messages] of [["empty",[]],["linked_user",[{role:"user",content}]]] as const){const res=await fetch(con.baseUrl.replace(/\/+$/,"")+"/chat/completions",{method:"POST",headers:{authorization:"Bearer "+key,"content-type":"application/json",accept:"text/event-stream"},body:JSON.stringify({model:chat.modelRef??"deepseek-v4.1-flash",messages,stream:true}),signal:AbortSignal.timeout(30000)});console.log(label,"status",res.status,"response_bytes",res.ok?0:(await res.text()).length);await res.body?.cancel().catch(()=>{});}await closeDb()})().catch(e=>{console.log("probe_error",e.name)})'
```

Keluaran: `empty status 400 response_bytes 208`; `linked_user status 200 response_bytes 0`. `response_bytes 0` pada HTTP 200 berarti body sengaja tidak dibaca agar tidak mencetak konten model.
